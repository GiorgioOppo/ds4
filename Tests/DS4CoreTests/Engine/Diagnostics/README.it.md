# Test della diagnostica dell'engine

`DiagnosticsTests.swift` valida i report diagnostici e la trasformazione dei
dati esposti da `DS4Engine` senza eseguire l'inferenza completa.

Mantieni le asserzioni sull'output concentrate su campi stabili e invarianti
piuttosto che sulla formattazione incidentale, a meno che il testo stesso non
sia un'interfaccia supportata.
