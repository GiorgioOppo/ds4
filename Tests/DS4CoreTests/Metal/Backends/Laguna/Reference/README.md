# Laguna reference tests

Device-free coverage of the Laguna CPU oracles with hand-computable fixtures:
layer-spec alternation, RMS norm, softplus gate guard, clampless SwiGLU, NeoX
pair rotation with and without YaRN (including the position-0 magnitude
scale), YaRN correction dims, the 10-expert router (biased selection, unbiased
weights, tie order), gated GQA attention over the F16 ring window, and the
attention/dense/MoE/output-head block compositions.
