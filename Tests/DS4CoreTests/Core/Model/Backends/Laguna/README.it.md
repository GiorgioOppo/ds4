# Test di configurazione Laguna

Queste fixture GGUF di soli metadati verificano l'esatta forma di Laguna S 2.1
senza richiedere il modello completo.  I test coprono l'alternanza per-layer
48/72 delle teste e la sua regola sliding-window, il requisito YaRN,
l'isolamento dell'architettura, i mismatch di forma e la normalizzazione degli
esperti.
