# Test di configurazione GLM 5.2

Queste fixture GGUF di soli metadati verificano l'esatta forma di GLM 5.2
senza richiedere il modello completo.  I test coprono la geometria derivata,
l'isolamento dell'architettura, i mismatch di forma, i metadati float
compatibili con F64 e la normalizzazione degli esperti.
