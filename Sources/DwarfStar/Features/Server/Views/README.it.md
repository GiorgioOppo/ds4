# Viste del server

`ServerView.swift` disegna la configurazione del listener, le opzioni di
autenticazione, lo stato e i controlli di avvio/arresto a partire da
`ServerController`.

Mantieni i segreti visivamente oscurati dove opportuno. La validazione e il
ciclo di vita del server appartengono al controller, non al body della vista.
