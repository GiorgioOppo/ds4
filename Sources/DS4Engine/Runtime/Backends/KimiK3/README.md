# Kimi K3 runtime backend

This directory is the DS4Engine boundary for the future `kimi-k3` backend.
`KimiK3BackendDefinition` registers the architecture and portable model
capabilities but advertises no generation capability yet. The gate stays off
until the tokenizer, five-part virtual reader, tensor map and decoder pass
independent parity tests.

Download URLs and package policy belong to `ModelManagement/Catalog`, not to
the runtime backend.
