# Model/Backends

Configurazioni portabili specifiche delle architetture supportate. Ogni backend
possiede forma, chiavi metadata e validazioni proprie; i contratti condivisi e
il rilevamento GGUF restano in [`../Common`](../Common/README.it.md).

- [`DeepSeekV4/`](DeepSeekV4/README.it.md): profili Flash/Pro operativi.
- [`GLM52/`](GLM52/README.it.md): contratto GLM 5.2 validato, runtime in sviluppo.
- [`Laguna/`](Laguna/README.it.md): contratto Laguna S 2.1 validato, decoder
  non ancora implementato.
- [`Qwen/`](Qwen/README.it.md): predisposizione senza decoder.
